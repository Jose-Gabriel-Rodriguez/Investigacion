# **Validación de escala para medir la motivación en el uso de Python en Probabilidad y Estadística en Educación Superior**

La enseñanza de probabilidad y estadística en estudiantes de ingeniería en sistemas es esencial para formar profesionales capaces de tomar decisiones basadas en datos. El uso de Python facilita la aplicación práctica de conceptos teóricos en datos reales.  
### **Objetivo**  
El estudio tuvo como objetivo validar un instrumento basado en la Escala de Motivación Académica para medir la motivación asociada al uso de Python en el aprendizaje de probabilidad y estadística. Se desarrolló bajo un enfoque cuantitativo, no experimental y transversal, con diseño instrumental. La validación de contenido se realizó mediante juicio de expertos y la prueba piloto incluyó 76 estudiantes.
### **Resultados**  
Los resultados mostraron una fiabilidad interna aceptable en las tres dimensiones: motivación intrínseca (α = 0.794), desmotivación (α = 0.872) y motivación extrínseca (α = 0.683). El alfa global (α = 0.646) sugiere margen de mejora. El análisis factorial exploratorio identificó tres factores coherentes con el modelo teórico, explicando el 74.74% de la varianza total. El análisis confirmatorio respaldó esta estructura con índices de ajuste satisfactorios (CFI = 0.955, TLI = 0.942, RMSEA = 0.064)
### **Conclusiones**  
El instrumento presenta propiedades psicométricas adecuadas y puede aplicarse en contextos universitarios, especialmente en asignaturas que integran herramientas tecnológicas como Python. Estos hallazgos respaldan su uso para evaluar la motivación académica en el aprendizaje de probabilidad y estadística.
